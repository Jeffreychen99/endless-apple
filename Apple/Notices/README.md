# Protocol references and attribution

The framing and initialization implementation follows `sorokya/eo-protocol-recharged` (based on `cirras/eo-protocol`); its MIT notice is retained in `eo-protocol-MIT.txt`.

The challenge hash, number-encoding conventions and known hash test vectors follow Ethan Moffat's `eolib-dotnet`. Its package declares MIT licensing and Ethan Moffat as author. The enclosing EndlessClient MIT notice is preserved in the repository's root `LICENSE`. References are pinned in `docs/COMPATIBILITY.md`.

Official game graphics, maps, sounds and data are separate from these source licenses. Locally downloaded files and NuGet-supplied game assets are excluded from source control. The development app bundle is for this local workspace; it is not a redistribution release.
