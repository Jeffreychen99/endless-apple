# Retained desktop source assets

The bitmap-font source and `../Endless.World/Desktop/WeaponSpriteType.cs` were copied from Ethan Moffat’s EndlessClient (https://github.com/ethanmoffat/EndlessClient), upstream revision c68891c. They are the small inputs currently reused by the Apple build. Retain the upstream MIT notice in the root LICENSE. The full MonoGame client is a local, ignored reference and is not required to compile Apple projects.

Original official game archives are separately supplied local development assets; they are not included or relicensed here.
